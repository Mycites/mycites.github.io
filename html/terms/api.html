API

서로 다른 프로그램이 정해진 방식으로 요청하고 정보를 주고받게 해 주는 창구입니다.

쉬운 비유

API는 카페의 주문 창구와 같습니다. 손님이 메뉴판에 있는 방식대로 주문하면, 주문 창구가 주방에 전달하고 결과를 다시 알려 줍니다.

초보자용 예시

날씨 앱은 날씨 정보를 가진 서버에 API로 “서울의 오늘 날씨를 알려 주세요”라고 요청합니다. 서버가 돌려준 온도와 날씨를 앱 화면에 보여 줍니다.

수업에서 기억할 점

API는 프론트엔드와 백엔드, 또는 서로 다른 서비스를 연결하는 정보 교환의 약속입니다.
