JavaScript

웹페이지가 사용자의 행동에 반응하고 움직이도록 만드는 프로그래밍 언어입니다.

쉬운 비유

JavaScript는 집 안의 전기와 자동 장치와 같습니다. 버튼을 누르면 메뉴가 열리거나 화면에 변화가 생기게 합니다.

초보자용 예시

쇼핑몰에서 “장바구니에 담기” 버튼을 누르면 JavaScript가 이를 알아차리고 장바구니 숫자를 0에서 1로 바꾸며 “상품을 담았습니다”를 보여 줍니다.

즉, HTML이 버튼을 만들고 CSS가 버튼을 꾸민다면, JavaScript는 버튼을 눌렀을 때 무엇을 할지 정합니다.

수업에서 기억할 점

HTML은 구조, CSS는 꾸밈, JavaScript는 사용자의 행동에 반응하는 동작입니다.
