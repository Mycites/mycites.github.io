CITES 애완동물 관리
최소 기능 제품 계획

개인 브리더가 개체 정보와 증식 기록을 실제로 남기고 다시 찾을 수 있는 첫 출시 범위

1. MVP 한 문장

개인 브리더가 사육 중인 CITES 애완동물을 등록하고, 개체 사진·기본 증식 기록·연결 서류를 개체별로 저장·조회할 수 있는 개인용 웹 관리 도구.

첫 출시의 성공 기준은 “새 개체 1마리를 등록하고, 나중에 그 개체의 사진과 번식 정보를 1분 안에 다시 찾을 수 있는가”이다.

2. MVP에 포함할 기능

기능사용자가 할 수 있는 일첫 버전 범위

3. MVP에서 제외할 기능

아래 기능은 중요하지만, 첫 버전의 사용 흐름을 단순하게 유지하기 위해 다음 단계로 미룬다.

다음 단계로 미룰 기능이유
직원 계정·권한 관리첫 버전은 개인 브리더 한 명이 사용하는 흐름에 집중한다.
거래처·판매 관리개체·증식 기록이 먼저 안정적으로 쌓인 뒤 확장한다.
복잡한 서류 종류·법률 검토서류 연결만 우선 제공하고, 법률·행정 판단 기능은 제공하지 않는다.
자동 사진 압축·클라우드 용량 관리파일 업로드 흐름을 먼저 검증한 뒤 저장 비용과 함께 설계한다.
양도 후 자동 삭제·알림실수로 자료가 사라질 위험이 있으므로, 기록 축적 후 사용자 확인 방식으로 도입한다.
엑셀·기존 폴더 자료 가져오기새로 입력하는 기본 흐름을 먼저 완성한다.

4. 핵심 사용자 흐름

  1. 대시보드에서 새 동물 등록을 누른다.
  2. 종명, 이름·관리 번호, 보유 상태를 입력하고 대표 사진을 1장 등록한다.
  3. 등록 완료 후 개체 상세 화면에서 정보와 사진을 확인한다.
  4. 같은 서류에 포함된 다른 개체가 있다면, 서류 연결에서 함께 선택해 한 건으로 기록한다.
  5. 양도 또는 폐사가 발생하면 해당 서류에서 사유와 수량을 남긴다. 남은 수량이 0이면 서류는 사용 불가 상태가 된다.
  6. 산란 또는 부화가 발생하면 해당 개체에서 증식 기록 추가를 누른다.
  7. 대시보드와 개체 상세 화면에서 최근 증식 기록을 다시 확인한다.

6. MVP 완료 기준

  • 사용자가 새 개체를 등록하고 대표 사진을 연결할 수 있다.
  • 등록한 개체가 목록과 상세 화면에 같은 정보로 표시된다.
  • 개체별로 산란·부화 정보를 1건 이상 등록하고 다시 볼 수 있다.
  • 서류 1건을 여러 개체에 연결하고, 연결된 모든 개체의 상세 화면에서 다시 볼 수 있다.
  • 서류별 대상 종과 처음 관리 수량을 입력하고, 양도·폐사에 따른 남은 수량과 사용 가능 여부를 확인할 수 있다.
  • 서류 목록에서 사용 가능한 서류와 사용 불가 서류를 구분해 볼 수 있다.
  • 모바일 화면에서도 제목, 입력 항목, 다음·저장 버튼이 잘린 곳 없이 보인다.
  • 서류·법률 판단 기능이 아니라 개인 기록 관리 도구임을 화면에 명확히 안내한다.

7. 구현 순서

  1. 동물 등록 화면의 3단계 UI를 만든다.
  2. 등록한 개체가 목록과 상세 화면에 보이도록 연결한다.
  3. 개체 상세 화면에 증식 기록 등록을 추가한다.
  4. 서류 1건을 여러 개체에 연결하는 기능을 추가한다.
  5. 서류별 관리 수량과 양도·폐사 차감 기록을 추가한다.
  6. 서류 목록에서 남은 수량과 사용 가능 여부를 확인한다.
  7. 대시보드에 실제 등록 현황과 최근 기록을 표시한다.
  8. 모바일 폭에서 입력 화면과 버튼이 잘 보이는지 확인한다.
