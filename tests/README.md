# 등록·서류 추출 검사

Node.js와 Playwright를 사용할 수 있는 환경에서 실행합니다.

```sh
node tests/registration.cjs
node tests/records.cjs
node tests/document-events.cjs
```

기본값은 Playwright Chromium입니다. 설치된 Edge를 사용하려면 환경 변수
`BROWSER_CHANNEL=msedge`를 설정합니다. `TEST_SCREENSHOTS`에 기존 폴더를 지정하면
1280·375·320px 화면을 저장합니다.

검사는 임시 로컬 서버와 별도 브라우저 저장소를 사용합니다. 실제 사용자 기록을
읽거나 수정하지 않습니다. PDF와 OCR용 이미지는 메모리에서 생성합니다.
PDF.js와 Tesseract.js의 도구·언어 자료를 다운로드하므로 인터넷 연결이 필요합니다.

검사 범위:

- 학명 일치, 중복 연결 방지, 소진·연결 완료 수량, 선택 변경과 저장 시 재검증
- 동물 저장 실패 시 서류 연결 복구
- 등록 확인 화면, 저장한 서류 연결의 상세 화면 표시
- 실제 PDF 텍스트 추출, 이미지 OCR, 스캔 PDF OCR, 강제 OCR
- 추출 후보의 종명·학명·수량 확인과 입력란 반영
- 파일 선택 후 직접 입력·자동 읽기 선택, 수동 저장 시 OCR 다운로드 미실행
- 한글·영문 서류 제목과 관리·허가·발급번호 후보, 여러 번호의 수동 선택
- 이름·번호의 개별 반영, 기존 입력 보호, 원본 확인 후 수정한 후보 반영
- 잘못된 PDF, 용량 초과, 취소, 모바일 가로 넘침
- 기존 서류 선택과 수량 초과 경고, 동물 복사 및 수정
- 서류 수정 시 첨부파일 유지, 수량 축소 제한, 동물·서류 삭제 확인과 취소
- 동물 삭제 시 연결과 증식기록 정리, 다른 동물·서류 보존
- 양도·폐사 서류 저장 시 동물 상태와 원본 서류 수량의 일괄 반영 및 실패 복구
- 중복 처리 방지, 처리 서류 수정 시 중복 차감 방지, 처리 서류 삭제 시 되돌리기
- 처리된 동물의 보유 수 제외, 양도·폐사 서류의 일반 연결 후보 제외

양도·폐사 서류는 보유 중·양도 예정이며 양수·수입 서류가 연결된 동물을 선택합니다.
종과 수량은 선택 개체에서 생성합니다. 연결된 각 원본 서류에 자동 감소 기록을 남깁니다.
이미 수동 감소를 기록해 잔여 수량이 부족한 경우에는 중복 차감하지 않고 저장을 막습니다.
처리 서류는 제목·관리번호·파일만 수정할 수 있습니다. 종류·동물을 바꾸려면 처리 서류를
삭제해 자동 반영분을 되돌린 뒤 다시 등록합니다. 사용 중인 원본 서류의 삭제도 막습니다.

현재 추출은 파일 1MB, PDF 20쪽, 실행 3분까지입니다. 텍스트가 부족한 PDF 페이지는
자동 OCR을 사용하며, 글자와 이미지가 섞인 페이지는 전체 OCR 버튼으로 다시 읽을 수
있습니다. 종 항목 후보는 같은 줄에 있는 학명·한글 종명·수량을 우선 찾습니다.
여러 줄이나 복잡한 표는 추출문을 참고해 직접 보정해야 하며, 원본 확인 후 반영합니다.
추출은 브라우저에서 실행되고 문서 파일은 인식 서버에 업로드하지 않습니다.
